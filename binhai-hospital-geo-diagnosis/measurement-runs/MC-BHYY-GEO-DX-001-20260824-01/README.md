# MC-BHYY-GEO-DX-001-20260824-01 实测证据目录

本目录对应滨海医院 GEO 诊断项目的一次手机 App 流程评估运行，不是正式客户基线，也不用于认证现实世界中的医院名称、资质或医疗质量。

## 证据来源

- R0026：豆包手机实测原始包，33 张。
- R0027：DeepSeek 手机实测原始包，33 张。
- R0028：通义千问手机实测原始包，33 张。
- R0029：腾讯元宝手机实测原始包，33 张。
- 合计：132 张，与冻结配置的计划总量一致。

四个原始 ZIP 保存在 `source-materials/current/`。`raw-images/` 是从原始 ZIP 解出的本机查看缓存，不重复提交到仓库；需要时可从 R0026—R0029 重新解出。

## 目录说明

- `derived-ocr/`：由原图生成的 OCR 辅助文本，不替代原图，不单独作为最终评分证据。
- `evidence-inventory.csv`：132 张证据的结构化清单和初步识别字段。
- `query-label-corrections.csv`：文件名题号与画面可见问题不一致时的元数据纠正表；原图和原文件名保持不变。
- `timing-qc.csv`：压缩包条目时间的辅助检查；该时间不是完整的手机采集时间证明。
- `first-pass-mention-summary.csv`：基于 OCR 的目标机构提及候选，仅供后续人工核图定位。
- `inventory-summary.json`：本次收件结构质检摘要。

## 使用边界

1. 最终转录与评分以手机原始截图的可见内容为准。
2. OCR 漏字、错字或拼接问题不得反向改写原始证据。
3. 腾讯元宝第一轮的 4 个题号错位只修正分析元数据，不重命名或覆盖原图。
4. 当前仅完成收件、结构和初步定位质检，尚未形成最终诊断指标或客户结论。
